#🗄️ Estudos de Banco de Dados

Bem-vindo ao meu repositório de estudos dedicado a **Banco de Dados**! Este espaço foi criado para documentar minha jornada de aprendizado, registrar anotações teóricas, armazenar scripts práticos e organizar projetos sobre bancos de dados relacionais e não-relacionais (NoSQL).

---

## 📌 Objetivos

- Compreender a teoria e os conceitos fundamentais de modelagem de dados.
- Dominar a linguagem **SQL** (DDL, DML, DQL, DCL, TCL).
- Explorar diferentes Sistemas Gerenciadores de Banco de Dados (SGBDs).
- Praticar a otimização de consultas (indexing, planos de execução).
- Estudar arquiteturas NoSQL e suas aplicações específicas.

---

- [x] Modelo Entidade-Relacionamento (MER / DER)
